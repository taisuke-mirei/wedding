# Taisuke & Mirei Wedding — 当日用Webサイト

結婚式のペーパーアイテム（プロフィールブック・席次表・メッセージカード）の代わりになる、スマホ向けの1ページサイトです。ビルド不要で、このフォルダをそのまま GitHub Pages で公開できます。

## ファイル構成

| ファイル | 役割 | 触る場面 |
|---|---|---|
| `index.html` | 画面の構造・デザイン（CSS）・動き | デザインを変えるとき |
| `guests.js` | ゲスト名簿（ID・名前・卓・席・個別メッセージ） | 名簿を入れるとき |
| `content.js` | プロフィール、一問一答、思い出の写真、メニュー、ドリンク | 内容を入れるとき |
| `assets/` | 画像（背景の空港平面図、写真） | 写真を追加するとき |

## ゲスト別の表示

`https://<公開URL>/?id=a1b2` のように `?id=` を付けて開くと、`guests.js` の名簿と照合して次のように表示します。

- Gate 06 に、その人の名前・卓・席・個別メッセージ
- Gate 04 の席次表で、その人の卓と席を強調

`id` がない、または名簿にない場合は、共通メッセージを表示します。

## 写真の入れ方

1. 画像を `assets/` に置く（長辺 1200〜1600px、1枚 200KB 前後が目安）
2. `content.js` の `src` や `MEMORY_PHOTOS` に `"assets/ファイル名.jpg"` と書く

## デザインの変え方

色とフォントは `index.html` 冒頭の `:root { … }` にまとめてあります。各セクションは `<!-- ===== Gate 0X … ===== -->` のコメントで区切っています。

## 手元での確認

```
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/?id=a1b2` を開きます。

## 公開前のチェック

- `guests.js` を本番の名簿に差し替え、`FILL_EMPTY_SEATS_WITH_DUMMY` を `false` にする
- ID は推測されにくいランダムな文字列（8文字以上）にする
- iPhone Safari、Android Chrome、LINE 内ブラウザで表示を確認する
- 式の後に公開を停止する
